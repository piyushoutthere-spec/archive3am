## How this works?
Ok i was in a hurry and made this so i will explain how this works. Enter the web and access the main dashboard. You can browse three case files and select each one to view its details. Explore six recovered images and open the available doc to uncover more information related to different incidents. Some files are restricted and display denied alert. use the search bar to find specific words accross case files, documents and evidence. The terminal must be started with HELP commands (all lowercase btw). finally the in gallery by clicking the first three images to uncover hidden clues. Finally you will get a message too.
